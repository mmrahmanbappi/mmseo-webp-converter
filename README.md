# MMSEO WebP Converter

Free WordPress plugin: **backs up first, converts the whole Media Library to compressed WebP, updates every image reference, and restores everything with one click.**

- **Download page (public):** https://mmrahmanbappi.github.io/mmseo-webp-converter/
- **Direct download:** https://mmrahmanbappi.github.io/mmseo-webp-converter/downloads/mmseo-webp-converter-1.1.0.zip
- Requires WordPress 6.2+, PHP 7.4+, GD or Imagick with WebP. License GPL v2 or later.

## Repo layout

| Folder | What it is |
|---|---|
| `mmseo-webp-converter/` | The plugin itself (this is what gets zipped and submitted to WordPress.org) |
| `docs/` | The public detail/download page (GitHub Pages), screenshots, `sitemap.xml`, `robots.txt`, and the ZIP |
| `qa/` | The strict QA harness (`qa2.php`) and its runner (`run-all.bat`) |
| `NOTES.md` | Project notes: status, decisions, how to test, what is left |

See `NOTES.md` for everything needed to continue work later.
